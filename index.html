Using jQuery Selectors and Events

Hover Over Me!

*jQuery Selectors Used*

#changeTextBtn
Selects the button with the id="changeTextBtn".
#freshText
Selects the paragraph with the id="freshText" so its text can be changed, hidden, or shown.
#hideTextBtn
Selects the button that hides the paragraph when clicked.
#showTextBtn
Selects the button that shows the paragraph when clicked.
#box
Selects the element with the id="box" so its color and text can change when the mouse moves over or away from it.
#animateBtn
Selects the animation button.
#animateBox
Selects the image that is animated when the animation button is clicked.
